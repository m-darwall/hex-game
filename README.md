# hex-game
An incomplete implementation of a catan-like game for web.

## current features
- displays a game board based on a template stored in a json file
- game board can include random elements like tile, number and port placements
- json files for a standard randomised board, a board with a contiguous woodland, a biomed board and a board with islands
- incomplete classes for various other game elements

Unlikely to be completed but a work in progress for fun because I like playing catan.
